# Publikacja w App Store

Materiały do App Store Connect. Teksty są propozycją: przeczytaj je przed wklejeniem.

| Plik | Co zawiera |
|---|---|
| `opis.md` | Nazwa, podtytuł, opis, słowa kluczowe, kategoria (PL i EN) |
| `formularze.md` | Odpowiedzi do formularzy: prywatność, klasyfikacja wieku, eksport szyfrowania, notatki dla recenzenta |
| `zrzuty.md` | Wymagane rozmiary i lista ekranów do zrzutów |
| `polityka-prywatnosci.md` | Źródło polityki prywatności (PL i EN); kopia na przemyslaw.wilde.pl, adresy w pliku |

Kolejność: konto Apple Developer → nowa aplikacja w App Store Connect → formularze → zrzuty i opis →
Xcode: Product → Archive → Distribute App → App Store Connect → TestFlight → wysyłka do przeglądu.
